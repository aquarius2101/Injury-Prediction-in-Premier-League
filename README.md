# EPL Injury Forecasting
This machine learning project is conducted within the Data Mining & Machine Learning module during my 2nd year. I built and evaluated classification models to forecast player injury risk in the English Premier League, using player statistics from season 2015/2016 to season 2021/2022. Results showed moderate performance across all models. Random Forest achieved the strongest overall performance after tuning, with an AUC of 0.7433 and an injured class recall of 0.76, representing a notable improvement over baseline results and outperforming a prior work using the same dataset.

## Overview
This project aims to build a classification model to predict injured soccer players using a publicly available dataset. I built different machine learning models and compared results, performances of three algorithms – Support Vector Machine (SVM), XGBoost, and Random Forest for the binary classification task, using English Premier League (EPL) data from the 2015/2016 season to the 2021/2022 season. I followed the KDD methodology: Knowledge Discovery in Databases - Data Collection, Data Preprocessing, Data Transformation, Data Mining, Interpretation & Evaluation.

## Data

- **Source:** https://www.kaggle.com/datasets/krishanthbarkav/english-premier-leagueepl-player-statistics
- **File:** `original-data.csv`
- **Description:** This EPL dataset is relatively large, containing more than 3,000 instances and 14 attributes so it provides a sufficient basis for fitting machine learning models. It has been used to build four classification models in one study in 2023.
- **Size:** 14 attributes x 3,262 instances
